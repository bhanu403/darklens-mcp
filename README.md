# DarkLens MCP Server 🤖🔍

> **Real-time deceptive design and dark pattern compliance auditor for AI coding agents.**

[![npm version](https://img.shields.io/npm/v/darklens-mcp.svg)](https://www.npmjs.com/package/darklens-mcp)
[![License: MIT](https://img.shields.io/badge/License-MIT-purple.svg)](https://opensource.org/licenses/MIT)

DarkLens MCP connects **Cursor, Windsurf, Claude Desktop, Antigravity, Lovable, v0, and Cline** directly to the DarkLens compliance auditing engine. Your AI coding agent can automatically audit staging URLs, check newly generated JSX/HTML components for deceptive patterns (GDPR, FTC Act Sec. 5, CCPA, EU DSA), and fix non-compliant UI before code is committed.

---

## ⚡ Quickstart Configuration by Coding Agent

### 1. 🖱️ Cursor
1. Go to **Cursor Settings** (`Ctrl + ,` or `Cmd + ,`) → **Features** → **MCP**.
2. Click **+ Add New MCP Server**.
3. Fill in:
   * **Name:** `darklens`
   * **Type:** `command`
   * **Command:** `npx -y darklens-mcp`
   * **Environment Variables:** `DARKLENS_API_KEY=dl_live_YOUR_KEY`
4. In Cursor Chat or Composer, prompt:
   > *"@darklens audit my checkout page and fix any illegal dark patterns."*

---

### 2. 🌊 Windsurf (Codeium)
Add to `~/.codeium/windsurf/mcp_config.json`:
```json
{
  "mcpServers": {
    "darklens": {
      "command": "npx",
      "args": ["-y", "darklens-mcp"],
      "env": {
        "DARKLENS_API_KEY": "dl_live_YOUR_KEY"
      }
    }
  }
}
```

In Lovable, Bolt.new, or v0 terminal or agent custom tool integrations, execute:
```bash

```
Or instruct the agent to run DarkLens CLI on preview URLs:
```bash
npx darklens <your-preview-url> --key $DARKLENS_API_KEY
```

## 🛠️ Exposed MCP Tools

| Tool | Description |
| :--- | :--- |
| **`darklens_audit_url`** | Audits any public or staging URL. Returns compliance score (0-100), pass/fail, and full findings with legal citations. |
| **`darklens_audit_html`** | Audits raw HTML/JSX markup generated by the AI agent before it writes files to disk. |
| **`darklens_get_fair_pattern_guide`** | Returns exact compliant alternatives and regulatory articles for any pattern (e.g. `forced_continuity`, `confirmshaming`). |
